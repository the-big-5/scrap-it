# Spec Directory

This directory contains the single source of truth for ScrapIt product, flows, UI, and tech architecture.

- For instructions on how to use this directory with AI coding agents and human teammates, see **[SPEC_GUIDE.md](../SPEC_GUIDE.md)**.
- For the standing rules enforced on agents every session, see **[AGENTS.md](../AGENTS.md)**.

## Structure
- `product.md`: App concept, goals, non-goals, and open questions.
- `flows.md`: Step-by-step user flows (F1, F2, etc.).
- `tech.md`: Architecture, platforms, frameworks, data models, and boundaries.
- `ui.md`: Screen definitions, states, and links to Figma.
- `changes/`: Active change files following the `00X-name.md` format.
- `changes/archive/`: Completed and merged change files.
